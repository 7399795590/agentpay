Quickstart

Create your first agent and run a payment flow in under 5 minutes.

Step 1 — Create an agent

POST /agents/create 
curl -X POST https://web-production-32de5.up.railway.app/agents/create \
  -H "Content-Type: application/json" \
  -d '{"name": "my-first-agent"}'

Response:

{
  "ok": true,
  "agent": {
    "id": "a1b2c3d4e5f6",
    "name": "my-first-agent",
    "balance": 0,
    "currency": "USD"
  },
  "api_key": "ap_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
}
⚠️ Save the api_key! It's shown only once. Store it securely.

Step 2 — Top up balance

POST /agents/{id}/topup 
curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/topup \
  -H "Authorization: Bearer ap_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"amount": 1000, "currency": "USD"}'

Step 3 — Charge for a service

POST /agents/{id}/charge 
curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/charge \
  -H "Authorization: Bearer ap_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"amount": 25, "description": "GPT-4 API call"}'

Authentication

AgentPay uses bearer-token authentication. Each agent gets a unique API key.

Header format

Authorization: Bearer ap_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Security rules
  • ✅ Never expose your API key in client-side code
  • ✅ Store keys in environment variables (.env)
  • ✅ Rotate keys if leaked (create a new agent)
  • ❌ Never commit keys to GitHub
  • ❌ Never share keys in public channels

Error Handling

All errors return JSON with an ok: false field and an error message.

Code Meaning Common cause
200OKSuccess
201CreatedAgent/subscription created
400Bad RequestInvalid input (missing name, bad amount)
401UnauthorizedMissing/invalid API key
403ForbiddenWrong admin key
404Not FoundAgent/subscription doesn't exist
409ConflictAlready refunded, duplicate name
402Payment RequiredInsufficient balance
429Too Many RequestsRate limit exceeded
500Server ErrorContact support

Example error response

{
  "ok": false,
  "error": "Insufficient balance (need 100, have 50)"
}
POST /agents/create

Create a new agent with a starting balance of $0. Returns a unique API key.

Request body

Field Type Required Description
namestringYesUnique agent name (max 100 chars)
emailstringNoOptional contact email
currencystringNoUSD / EUR / GBP (default: USD)

Example

cURL 
curl -X POST https://web-production-32de5.up.railway.app/agents/create \
  -H "Content-Type: application/json" \
  -d '{"name": "my-agent", "email": "me@example.com"}'
GET /agents/{agent_id}

Retrieve an agent's current balance and metadata. No auth required.

cURL 
curl https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6
POST /agents/{agent_id}/topup

Add funds to an agent's balance. Amount in cents (integer).

💡 Amount is in cents: $10.00 = 1000
cURL 
curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/topup \
  -H "Authorization: Bearer ap_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{"amount": 1000, "currency": "USD"}'
POST /agents/{agent_id}/charge

Deduct funds from an agent's balance. Returns 402 if insufficient.

cURL 
curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/charge \
  -H "Authorization: Bearer ap_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{"amount": 25, "description": "GPT-4 call"}'
POST /agents/{agent_id}/refund

Refund a previous charge. Protected against double-refunds (returns 409).

cURL 
curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/refund \
  -H "Authorization: Bearer ap_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{"transaction_id": 42, "reason": "Customer request"}'
GET /agents/{agent_id}/transactions

List all transactions for an agent (newest first).

cURL 
curl https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/transactions \
  -H "Authorization: Bearer ap_xxxxx"
POST /agents/{agent_id}/subscriptions/create

Create a recurring subscription. Intervals: daily, weekly, monthly, yearly.

curl -X POST https://web-production-32de5.up.railway.app/agents/a1b2c3d4e5f6/subscriptions/create \
  -H "Authorization: Bearer ap_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{"name": "Pro Plan", "amount": 2900, "interval": "monthly"}'
GET /agents/{agent_id}/subscriptions

List all subscriptions for an agent.

POST /agents/{agent_id}/subscriptions/{sub_id}/cancel

Cancel an active subscription (soft delete).

POST /agents/{agent_id}/stripe/checkout

Create a Stripe Checkout session. Returns a checkout_url.

POST /stripe/webhook

Stripe webhook handler. Verifies signature with STRIPE_WEBHOOK_SECRET.

GET /stripe/config

Returns the Stripe publishable key for frontend integration.

GET /admin/stats

Platform statistics. Requires ADMIN_API_KEY.

curl https://web-production-32de5.up.railway.app/admin/stats \
  -H "Authorization: Bearer your_admin_key"
GET /admin/agents

List all agents (admin).

DELETE /admin/agents/{agent_id}

Delete an agent and all associated data (admin).

POST /admin/agents/{agent_id}/balance

Set an agent's balance directly (admin). Useful for migrations and corrections.

GET /admin/audit

Retrieve audit log entries. Query params: limit, agent_id, action.

POST /admin/run-billing

Manually trigger billing for due subscriptions (admin).

GET /health

Health check endpoint. Returns {"ok": true} when the API is up.
