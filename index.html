Frequently asked questions

What is AgentPay? ▾

AgentPay is a payment API for AI agents. It gives each agent a balance, an API key, and a way to charge for services — without needing credit cards or human verification.

How is this different from Stripe? ▾

Stripe is built for humans with credit cards. AgentPay is built for autonomous software. We handle the API-key-based auth, per-agent balances, and audit trails that autonomous systems need.

Do I need a credit card to start? ▾

No. The Free plan gives you an API key instantly — no credit card required. Upgrade to Pro or Business when you're ready.

What languages do you support? ▾

Any language that can make HTTP requests. We also provide an official Python SDK, and a Node.js SDK is coming soon. The REST API is fully documented with OpenAPI.

How do refunds work? ▾

Every charge can be refunded with a single API call. We protect against double-refunds and log everything in the audit trail.

Is my data safe? ▾

Yes. All API calls use bearer-token auth. Audit logs capture every action. We use PostgreSQL (Neon) with encrypted connections. Stripe handles payment data (PCI-DSS compliant).
