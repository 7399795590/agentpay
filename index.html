The Problem

🤖

Agents are autonomous

Claude Code, Cursor, AutoGPT — they work without human supervision.

💳

Every transaction requires approval. That kills automation.

⚡

Microtransactions

176M+ agent transactions worth $73M in the past year. Most under $0.30.

The Solution

A simple API that lets agents:

  • ✅ Hold a prepaid balance (in USD cents)
  • ✅ Pay for services autonomously
  • ✅ Log every transaction
  • ✅ Integrate in 5 lines of code
curl -X POST https://api.agentpay.dev/agents/abc123/charge \
  -d '{"amount": 30, "description": "API call"}'
